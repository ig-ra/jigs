How to read this

Weighted is the IGR-14 cost proxy (cache read 0.1×, cache write 1.25–2×, output 5×, model multiplier), Claude only, uncalibrated. Raw adds new input, cache read, cache write and output as plain tokens (about 90% is cheap cache read) and is the only way to see Codex.

A call's whole cost goes to the tool it used (or text when it used none, mixed when it used several), including re-reading the context. Stage unknown means the ticket's stage markers had not been seen yet. Develop and review are read from tk step commands, which only exist after change #3 (10-10): before it that cost sits under design or unknown, so compare totals across #3, not stages.

Only calls tagged with a ticket count. Tickets are grouped by the day their first call happened. Tickets started in the last 2 days of data may still be running (90% of tickets finish within 1.4 days), so they are faded in the charts and left out of the before/after comparison. The numbered flags are hand-picked commits from stats/milestones.json; the expected effect is my reading of each commit message. Before/after compares tickets started in a window around the commit. That is observation, not proof: ticket size, neighbouring changes and small samples all move it, and quality is not measured here.
